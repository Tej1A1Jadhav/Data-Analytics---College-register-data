# Student and Teacher Performance Analytics

## Overview
This project focuses on analyzing **student and teacher performance data** using **Data Analytics techniques**.  
The main workflow involves:
- Collecting data from a **MySQL database** (students, teachers, subjects, marks, attendance, feedback).
- Cleaning and preprocessing the data using **Pandas**.
- Visualizing insights with **Plotly** for interactive charts and graphs.

---

## Data Sources
- **Students Table** → student details, year, department  
- **Teachers Table** → teacher details, department  
- **Subjects Table** → subject details  
- **Marks Table** → exam scores, subject, teacher, date  
- **Attendance Table** → student presence/absence records  
- **Feedback Table** → student ratings for teachers/subjects  

---

## Data Cleaning (Pandas)
- Handle missing values  
- Standardize categorical fields (e.g., attendance status)  
- Convert marks and ratings to numeric values  
- Remove duplicates  

---

## Key Analytics
- **Average Marks per Student** → overall performance  
- **Average Marks per Subject** → subject difficulty trends  
- **Pass Percentage** → percentage of students scoring ≥ 40  
- **Teacher Ratings** → average rating per teacher  
- **Attendance vs Marks** → correlation between presence and performance  
- **Trend Analysis** → marks and attendance patterns over time  

---

## Visualizations (Plotly)
- Histogram → Marks distribution  
- Bar Charts → Subject averages, Teacher ratings  
- Scatter Plot → Attendance vs Marks (with regression trendline)  
- Line Charts → Marks trend, Attendance trend  
- Pie Chart → Pass vs Fail ratio  
- Box Plot → Spread of marks  
- Heatmap → Subject vs Teacher performance  

---

## Outcomes
- Clear insights into student performance and teacher effectiveness  
- Interactive visualizations for deeper exploration  
- Demonstrates how **data analytics** can improve decision‑making in education
